# 临笺 · Linjian

面向规培医生、住院医师的 Android 与 iOS 临床记录与患者管理工具。

临床工作中的信息常常散落在纸笔、备忘录和不同页面里。临笺把患者资料、查房记录、待办事项、检验检查和门诊跟诊整理到一起，方便在手机和平板上随手记录、回看和交接。

## 适合哪些场景

- **住院查房**：按患者整理病情变化、查房意见、上级交代和后续关注事项。
- **临床待办**：记录查看结果、汇报、沟通、随访和病历工作，跟进完成情况。
- **检验检查**：整理报告、图片资料和结构化结果，回看变化趋势。
- **入院问诊与病历整理**：使用问诊模板采集资料，按需要调整记录项目。
- **门诊跟诊与学习**：记录就诊经过、老师经验和复盘内容，积累自己的临床笔记。
- **排班与提醒**：管理排班日历、临床提醒和轻量出院随访。

## 手机与平板之间接着用

临笺支持用户配置 WebDAV 云盘，在设备之间手动执行加密双向同步；也支持建立带密码的完整备份。

跨设备同步需要两端使用一致的云盘配置和同步密钥。备份与同步用途不同：定期建立独立备份，方便在需要时恢复资料。

## 数据与隐私

日常记录默认保存在当前设备。云端同步需要用户主动配置并执行。

- 可选六位数字应用锁，减少他人直接进入界面的机会。
- 完整备份使用单独设置的密码加密。
- WebDAV 同步内容在本机加密后上传。
- 应用锁用于界面访问控制，不代表本地数据库已由锁屏密码加密。

请按所在医疗机构的要求管理患者资料、录音、截图和导出文件。反馈问题时，请使用虚构案例或充分脱敏的材料。

## 关于 AI 功能

临笺另有独立的 AI 测试版本，正在探索临床问答、图片资料整理和病历草稿辅助等功能。AI 测试版与正式版使用独立的应用数据空间。

AI 功能需要配置第三方模型服务商的 API Key；用户主动使用相关功能时，所选内容可能发送给对应服务商。具体能力、费用和资料发送范围以所使用版本的说明与操作提示为准。

AI 生成内容需要使用者核对，不可直接作为诊断、处方或治疗决策的依据。
